8-Bit CPU

An 8-bit CPU based on the SAP (Simple-As-Possible) architecture built on breadboards as an exercise to learn about computer architecture. This project is based on Ben Eater's 8-bit Computer.

Clock

Multivibrator circuits are used to generate two-state signals. Three configurations are used: astable, monostable, and bistable.

  • Astable multivibrator acts as a free-running clock. The 1uF capacitor continually charges and discharges, causing the 555 timer to toggle between high and low. The potentiometer allows clock speed adjustment.
  • Monostable multivibrator has one stable state. When triggered by the push button, it temporarily flips to the unstable state for a set period of time before returning to the original stable state.
  • Bistable multivibrator acts as an SR latch. It is used to select between the free-running clock and the manual clock.

Arithmetic Logic Unit (ALU)

Arithmetic logic unit (ALU) is a combinational circuit for performing arithmetic and logical or bitwise operations on binary numbers.

The SAP-1 computer contains a simple ALU, consisting of logic gates and flip-flops, capable of binary addition and subtraction on data in A-register (accumulator) and B-register.

Registers hold data, memory addresses, or instructions. Inside the ALU, the 8-bit numbers in A-register and B-register are added in the sum register. To create

To perform addition and subtraction on 8-bit numbers, two 74LS283 ICs (4-bit binary full adders) are cascaded together, taking data from registers A and B.

  • Addition: When SUBTRACT is LOW, B-register passes through XOR gates unchanged, and the 74LS283 adders sum A-register and B-register.
  • Subtraction: When SUBTRACT is HIGH, B-register is inverted by XOR gates. The same HIGH SUBTRACT signal feeds into the Carry-In pin of the lower 74LS283 adder, converting B-register into 2's complement.
