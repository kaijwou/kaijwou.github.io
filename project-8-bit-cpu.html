8-Bit CPU

An 8-bit CPU based on the SAP (Simple-As-Possible) architecture built on breadboards as an exercise to learn about computer architecture. This project is based on Ben Eater's 8-bit Computer.

Multivibrators

Multivibrator circuits are used to generate two-state signals. Three configurations are used: astable, monostable, and bistable.

  • Astable multivibrator acts as a free-running clock. The 1uF capacitor continually charges and discharges, causing the 555 timer to toggle between high and low. The potentiometer allows clock speed adjustment.
  • Monostable multivibrator has one stable state. When triggered by the push button, it temporarily flips to the unstable state for a set period of time before returning to the original stable state.
  • Bistable multivibrator acts as an SR latch. It is used to select between the free-running clock and the manual clock.
